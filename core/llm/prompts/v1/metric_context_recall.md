# 规则
- 要点要小而独立：一个要点一条事实（数值、单位、部件名、步骤序号都算独立信息）。
- supported = 1 表示该要点能被上面的材料支持（允许同义表述）；0 表示材料里没有或冲突。
- 不许用你自己的知识补全；也不许把参考答案里根本没有的内容拆成要点。
- 参考答案为空或本身就是"无法回答"时，items 返回空列表。
