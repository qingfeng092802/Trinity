# 输出格式
只输出一个 JSON 对象，字段如下，不要任何解释或 markdown 代码块：

- `thought`：字符串。一句话说明你打算怎么做，会写入轨迹供回放。
- `tool_name`：字符串或 null。要调用工具时填工具名（只能从上面的清单里选）；不需要工具时填 null。
- `tool_args`：对象。工具入参，键名必须与工具说明一致；不需要工具时填空对象 {}。
- `answer`：字符串。本步骤的最终结论，要具体到可直接呈现在最终答案里；若已调用工具，可留空，由工具返回结果补充。

# 判断规则
1. 只有当工具能实质性提升结论质量（例如需要外部事实、需要精确计算、需要读写文件）时才调用工具；纯推理、纯写作、纯总结一律直接给 answer。
2. 一次只做当前这一条子步骤的事，不要顺带完成后面的步骤。
3. 如果当前子步骤依赖的信息在前面的结论里已经具备，直接用，不要重复获取。
4. 引用 knowledge_search 的结果时，结论中必须标注来源（文档名与片段位置），检索失败时说明原因并继续可完成的步骤。
